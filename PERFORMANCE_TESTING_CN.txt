诊断工具
  performance_diagnostic_build.py：生成相同的 Context 调用计数/计时代理 EXE。
  performance_diagnostics.py：CPU Context / API / GPU timer 诊断。
  performance_ablation_build.py：创建独立常量缓冲区/描述符堆复用的实验 DLL。
  performance_ablation.py：实验 DLL 与原候选的配对测试。
  performance_emit.py：相同官方发射切换下的 Adhesion/Goo Gun 补测。
  performance_shader_audit.py：从两个实际 DLL 扫描并比较 84 份可执行 shader 程序。
  performance_audit.py：窗口、输入、睡眠、帧数、输出与完成状态审计。
  performance_report.py：从完整数据生成中文报告及标准 PNG 图表。

诊断 DLL 不是本次正式替换 DLL；它们只完成选定场景的性能消融，未经全 API 与外部 Context 生命周期回归验收。必须根据最终报告的范围解释结果。
